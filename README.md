# Умная таблица

Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» Яндекс Практикума.

## Возможности

* отображение данных о продажах;
* пагинация;
* сортировка по дате и сумме покупки;
* фильтрация по дате, покупателю, продавцу и диапазону суммы;
* поиск по дате, покупателю и продавцу;
* сброс фильтров.

## Технологии

* HTML5;
* CSS3;
* JavaScript;
* Vite.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

Проверить production-сборку:

```bash
npm run build
```
