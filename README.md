# Умная таблица

Учебный проект Яндекс Практикума: продолжение умной таблицы из проектной работы 6.2. В этой версии данные загружаются с учебного сервера.

## Возможности

* загрузка продаж, продавцов и покупателей через API;
* серверная пагинация: 10, 25, 50 или 100 строк на странице;
* серверная сортировка по дате и сумме покупки;
* серверная фильтрация по дате, покупателю, продавцу и диапазону суммы;
* серверный поиск по дате, покупателю и продавцу;
* сброс фильтров, поиска, сортировки и пагинации;
* сообщения о загрузке, пустом результате и ошибке запроса;
* защита от перезаписи таблицы запоздалыми ответами сервера.

## Данные и запросы

Адрес API: `https://webinars.webdev.education-services.ru/sp7-api`.

* `/sellers` — справочник продавцов;
* `/customers` — справочник покупателей;
* `/records` — записи о продажах.

Компоненты формируют параметры `search`, `filter[date]`, `filter[customer]`, `filter[seller]`, `filter[totalFrom]`, `filter[totalTo]`, `sort`, `limit` и `page`. Они передаются серверу через `URLSearchParams`. Полученные строки отображаются без локальной фильтрации, сортировки и разбиения на страницы.

Справочники и последний успешный результат кешируются. `api.getRecords(query, true)` позволяет повторить запрос без кеша. Статические датасеты стартер-кита не импортируются и не используются приложением.

## Запуск проекта

Команды выполняются в терминале из папки проекта, где расположен `package.json`. Для получения данных нужен доступ к учебному API.

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

Проверить production-сборку:

```bash
npm run build
```

## Структура

* `src/data.js` — запросы к API, кеширование и преобразование полей ответа;
* `src/main.js` — сбор состояния формы и асинхронная отрисовка;
* `src/components/table.js` — шаблоны строк и события формы;
* `src/components/pagination.js` — параметры страницы и обновление пагинатора;
* `src/components/filtering.js` — параметры фильтров и список продавцов;
* `src/components/searching.js` — параметр общего поиска;
* `src/components/sorting.js` — направление сортировки.
